# ERC 'Earth' — Implementation Roadmap

> This document accompanies the book **«ЖК «Земля» — Манифест взрослой цивилизации»** /
> **ERC 'Earth' — A Manifesto of Civilizational Adulthood**.
>
> The book describes a post-2037 world. The projects below are its working prototypes —
> things that can be built **today**, with existing technology, by small teams.
>
> Each project maps directly to a chapter. Each can start as an open-source MVP.
